📦 Estructura de esta sección

  1. Cada proyecto vive en su propia carpeta dentro de openwebinars/.
  2. La carpeta debe tener un index.html para poder ejecutarse y aparecer en el visor.
  3. Los estilos y scripts se referencian con rutas relativas (css/estilos.css, js/app.js).
  4. La plantilla _plantilla/ no se publica: sirve para copiarla y crear proyectos nuevos.
