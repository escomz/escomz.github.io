Ejercicios de repaso - DAM / Desarrollo de Aplicaciones Multiplataforma

Enunciado general

Haz una página web que muestre por cada ejercicio:

  • El enunciado del ejercicio.
  • Estilos CSS para hacerlo más vistoso.
  • Elementos necesarios: encabezados, enlaces, formularios y campos.
  • El resultado en una capa distinta a la del enunciado.
  • Código JS con comentarios exhaustivos línea por línea para poder explicarlo en clase.

Consejo: abre las herramientas de desarrollo (F12) para ver también la consola real del navegador.
