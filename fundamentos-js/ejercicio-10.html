Ejercicio 10. Número más grande de un array

Math.max() + operador de expansión ...

← Volver al índice

Enunciado

Crea una función que encuentre el número más grande en un array.

  • Usa el método Math.max() y el operador ... para "expandir" el array.
  • Math.max(3, 7, 2) devuelve 7 (recibe argumentos sueltos).
  • Math.max(...[3, 7, 2]) equivale a Math.max(3, 7, 2).

Ejemplo: [4, 19, 7, 100, 2] → 100

Elementos del ejercicio

Resultado

Array de ejemplo listo: 4, 19, 7, 100, 2
