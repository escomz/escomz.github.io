Ejercicio 19. Calcular el promedio de un array

reduce() para sumar y .length para dividir

← Volver al índice

Enunciado

Escribe una función que reciba un array de números y calcule su promedio.

  • Usa reduce() para sumar todos los números.
  • Divide la suma entre la longitud del array (length).
  • reduce((acumulador, valor) => acumulador + valor, 0) empieza en 0.
  • Ejemplo: [2, 4, 6] → suma 12 → promedio 4
