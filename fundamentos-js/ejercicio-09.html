Ejercicio 9. Revertir una cadena

split() + reverse() + join()

← Volver al índice

Enunciado

Escribe una función que tome una cadena como argumento y devuelva la cadena invertida.

  • Usa split("") para convertir la cadena en un arreglo.
  • Usa reverse() para invertir el arreglo.
  • Usa join("") para unirlo de nuevo en una cadena.

Ejemplo: "hola" → "aloh"

Elementos del ejercicio

Resultado

Escribe una cadena y pulsa "Invertir cadena".
