Ejercicio 4. Suma de dos números

prompt() para pedir datos y Number() para convertirlos

← Volver al índice

Enunciado

Escribe un programa que pida al usuario ingresar dos números y luego muestre la suma. Usa prompt() para pedir datos al usuario y Number() para convertir las entradas a números. Usa console.log() para mostrar el resultado.

  • prompt() devuelve SIEMPRE un string (o null si se cancela).
  • Number() convierte ese texto a número.
  • Si el texto no es válido, Number() devuelve NaN.
