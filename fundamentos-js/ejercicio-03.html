Enunciado

Declara un objeto persona con las propiedades más habituales, usando todos los tipos de datos, incluido un array y otro objeto. Muestra el contenido usando console.log y console.table.

  • Propiedades: nombre (string), edad (number), aprobado (boolean), …
  • Array: notas de las asignaturas.
  • Objeto anidado: dirección con calle, ciudad y código postal.
  • También null y undefined para completar los tipos.
