Ejercicio 21. Filtrar números mayores que un valor

filter() con condición "> valor"

← Volver al índice

Enunciado

Escribe una función que tome un array de números y un valor, y devuelva un nuevo array con los números que son mayores que ese valor.

  • Usa filter() para crear el nuevo array.
  • La condición de cada elemento es numero > valor.
  • Ejemplo: [3, 8, 1, 20, 5] con valor 5 → [8, 20]
