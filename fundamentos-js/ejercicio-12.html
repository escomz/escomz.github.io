Ejercicio 12. Filtrar números pares

filter() + operador resto %

← Volver al índice

Enunciado

Crea una función que tome un array de números y devuelva un nuevo array con solo los números pares. Usa filter() y el operador %.

  • filter() NO modifica el array original: crea uno nuevo.
  • Un número es par si n % 2 === 0.
  • Ejemplo: [1, 2, 3, 4, 5, 6] → [2, 4, 6]
