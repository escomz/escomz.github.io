Ejercicio 5. ¿Par o impar?

Verificación con prompt() y operador resto %

← Volver al índice

Enunciado

Crea un programa que verifique si un número ingresado por el usuario es par o impar.

  • Pide el número con prompt() y conviértelo con Number().
  • Un número es par si al dividirlo entre 2 el resto es 0: n % 2 === 0.
  • Si el resto es 1, el número es impar.
  • Usa una estructura de control if / else.
